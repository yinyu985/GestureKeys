# GestureKeys 产品与交互规范

面向开发和测试。本文以当前 macOS 客户端源码为基线，记录功能和控件的外观、状态与行为。修改交互时，同步更新对应条目和验收项。对外的下载和安装说明仍放在 [README](../README.md)。

## 1. 功能与规则

- **规则结构**：一条规则由名称、触发方式、执行动作、应用范围、启用状态和触发提示组成。触发方式支持快捷键、鼠标手势、鼠标单击和双击。鼠标规则支持右键、中键和第 4–8 键，不使用左键作为全局触发键。
- **内置预设**：按住右键向上划打开调度中心；普通右键单击保留系统菜单。此约定不覆盖用户自己保存的绑定。
- **作用范围**：「所有应用」是全局规则；也可只选一个应用。前台应用内，同触发方式的应用专用规则覆盖全局规则。同一范围内，两条已启用规则不得使用相同触发方式。单击和双击是不同触发方式。手绘和预设轨迹不因画布位置或尺寸不同而失去覆盖关系。近似并列时，只优先选取形状等价且唯一的应用专用规则；同一范围内的歧义或不同形状之间的歧义不执行。
- **动作**：下拉框按「自定义」「网页与标签页」「编辑」「窗口与系统」分组。自定义动作包括发送快捷键、打开应用、打开链接、打开文件或文件夹。实际可选动作以 [`ActionKind.groups`](../Sources/GestureCore/Models.swift) 为准，不把只为旧配置保留的动作自动加回菜单。
- **监听**：配置有效、有可执行规则、无规则冲突且所需权限齐全时自动启动，不设置额外的「开始监听」按钮。规则编辑、列表快捷键录入、确认弹窗和文件选择器在 GestureKeys 位于前台时暂停规则触发；普通主窗口不暂停。关闭窗口不退出进程，已启用规则继续在后台运行。
- **输入归属**：按下时记住前台应用、进程和规则上下文。中途切换应用或匹配后、派发前上下文已变则取消，不为旧动作改选目标。仅绑定单击／双击的按键，一旦离起点达到 10 pt，即交还原按下和拖动，后续拖动直接通过；只在容差内来回抖动仍算点击。该键已有手势规则时，离起点超过 10 pt 就按手势处理：没有匹配的手势则整笔按下、拖动和松开都不回放，也不弹出系统菜单，拖回起点同样如此；未拖动的右键单击仍回放为原生点击。没有手势规则的键照常回放拖动。双击间隔按鼠标事件的时间戳判定，不按处理速度判定。
- **反馈**：「触发提示」只控制是否短暂显示规则名称；「启用」才控制是否执行规则。绑定右键单击可能接管普通右键菜单；同时绑定同一个键的单击和双击时，单击要等待双击判定。
- 拖动时显示最新的手势轨迹。松手、取消手势、关闭轨迹或停止监听时，丢弃尚未显示的轨迹并收起已经显示的轨迹。一笔超过 10 秒或记录到 2048 点后不再接收新点，按未匹配处理，该笔随后的松开也一并吞掉。

## 2. 通用控件

尺寸单位为 pt。浅色、深色和跟随系统都使用 [`Ink`](../Sources/GestureKeys/Widgets.swift) 的颜色：强调色用于主操作和选中状态，危险色用于破坏性操作和错误。预览与状态文字不能只靠颜色传达含义。

| 控件 | 外观 | 状态与行为 |
| --- | --- | --- |
| 普通按钮 `QuietButton` | 高 27、圆角 5、12 pt 中等字重，左右内边距 10；次要按钮用中性色，主按钮用强调色，破坏性按钮用危险色 | 按下时底色加深；禁用时文字降低不透明度且不可触发。「保存」「添加规则」使用主样式，「取消」用次要样式。 |
| 列表图标按钮 `RuleIconButton` | 26 × 26 点击区，12 pt 图标；常态低对比，悬停时突出；删除悬停用危险色 | 编辑、复制、删除有独立点击区、工具提示和辅助功能标签。悬停不是执行条件。 |
| 互斥选项 `SelectionButton` | 复用普通按钮，用空心圆和实心圆区分未选与已选；已选项同时使用强调色 | 用于外观、应用图标和规则应用范围；有选中语义。单选按钮组不是下拉框。 |
| 开关 | macOS 迷你开关；行标签可在视觉上隐藏，但保留辅助功能名称 | 开／关语义固定。规则行开关写入失败时保留原值，并提示失败原因。 |
| 文本输入 | 编辑器宽 216、高 27，圆角 5；字段标签固定在左侧 | 占位文字不能代替标签。规则名称要求非空；网址要求完整的 `http://` 或 `https://` 链接。 |
| 快捷键录入 `ShortcutRecorder` | 等宽字显示组合键，未填写时显示「录入」；录制时改为「请按键」并使用危险色边框，键盘聚焦显示加粗边框 | 同时只允许一个控件录入。点另一行只给最后选中的行录一次；点击控件外、裸 `Esc`、再次点击或窗口失焦退出录制。字母和符号按当前 macOS 键盘布局显示，切换布局不改已保存的物理键码。取消保留旧值。触发键必须是带修饰键的组合或受支持的功能键，发送键不受这项限制。 |

### 下拉框

- **入口**：`ChoiceButton` 用单行文字显示当前值或占位提示，右侧箭头在收起时向下、展开时向上。高度 26、圆角 5；悬停或展开加深强调色，禁用时变淡且不弹出。
- **短选项**：`ChoiceMenu` 用单列 Popover。选项行高 26，当前项高亮并显示勾选；点选后更新绑定并关闭。用于「语言」「鼠标按键」「触发方式」「预设轨迹」。未选鼠标按键时，「触发方式」显示「选择方式」并禁用。
- **动作下拉框**：`ActionPages` 用双列 Popover，高 312；左侧宽 176 显示分类，右侧宽 242 显示该分类的动作，中间用 1 pt 分隔线。打开时定位到当前动作所属分类，未选动作时从第一类开始。点击分类只切换右侧列表，不改变已选动作，也不关闭弹层。选中动作后才更新草稿并关闭。右侧换分类时从该分类列表顶部开始。

### 滚动区和滚动条

项目自有的下列滚动区均为纵向 `ScrollView`，当前统一使用 `.scrollIndicators(.never)`：隐藏滚动条，不禁用滚动，也不绘制自定义滚动条。原生文件选择器、系统设置、颜色面板使用 macOS 的滚动行为。

| 位置 | 一起滚动 | 保持不动 |
| --- | --- | --- |
| 键盘／鼠标规则页 | 规则行和空状态 | 左侧导航、页标题、规则数、添加按钮、列标题、底部提示 |
| 通用／关于 | 页标题和内容卡片 | 左侧导航和主窗口底部提示 |
| 规则编辑器 | 名称、触发、画布、动作、范围等表单内容 | 顶部标题和底部提示、取消／保存按钮 |
| 动作下拉框 | 右侧动作列表 | 左侧分类 |
| 确认与信息弹窗 | 可选中的详情文本，滚动区最高 120 | 弹窗标题和按钮 |

## 3. 主窗口和规则列表

主窗口内容区域固定为 850 × 580。左侧导航宽 168，顺序为「键盘」「鼠标」「通用」「关于」。每项高 32，图标加文字；选中项有强调色边框、浅色底和选中语义。切换页面不会修改规则。

列表顶部显示规则数；无规则时显示「还没有规则」。键盘页先按修饰键、再按快捷键显示文本排序；鼠标页按按键分组。比较结果相同的规则保留原存储顺序。触发方式、执行动作、应用范围、触发提示、启用和操作六列与表头对齐，规则行高 34。

| 按钮或控件 | 行为 |
| --- | --- |
| 添加规则（`⌘N`） | 开空白草稿。键盘页使用键盘触发；鼠标页从未选按键的手势规则开始。非规则页、已有编辑器或确认弹窗时不可新建。 |
| 触发方式列 | 键盘规则可直接录入新组合并尝试保存；失败时保留原组合并弹出提示。鼠标规则显示按键和单击／双击或轨迹缩略图，点击打开编辑器。 |
| 执行动作、应用范围 | 点击打开该规则的编辑器。长文字单行截断，悬停提示补充完整信息。 |
| 触发提示、启用 | 两个独立开关，即时提交；启用时检查冲突。 |
| 编辑、复制、删除 | 编辑打开原规则草稿；复制打开带「副本」后缀的新草稿，默认停用；删除先确认，未确认不得删除。 |

底部提示区显示权限、执行失败和快捷键注册失败。`Ctrl+1` 注册失败时单独提示可能被 macOS 用于「切换到桌面 1」，指明调度中心设置路径，不自动改键，不拒绝保存规则。浏览器专用规则的失败提示在切回 GestureKeys 时仍可见；注册成功、该组合不再有已启用的有效规则或监听停止时清除。

## 4. 规则编辑器和弹窗

编辑器以 Sheet 打开，宽 478，高度随画布、附加字段和提示变化。全宽控件宽 216；并排控件各 104，中间间距 8。编辑器使用草稿；只有成功保存才更新规则。错误显示在底部，保留草稿；再次改动草稿时清除上次校验错误。

| 区域 | 按钮或控件 | 行为 |
| --- | --- | --- |
| 触发方式 | 快捷键录入，或「按键」和「触发方式」两个下拉框 | 鼠标方式为手势、单击、双击。仅在已选鼠标按键且方式为手势时显示轨迹区。 |
| 轨迹 | 「预设轨迹」、画布、「清空」 | 选择预设后立即预览；画布高 178、圆角 6、有点阵，拖动时实时显示，松手后记录有效手绘轨迹并移除预设标记。清空同时删除轨迹和预设标记；无轨迹时禁用。列表缩略图为 48 × 24，适配显示不改变原始轨迹。 |
| 执行动作 | 动作下拉框及附加控件 | 发送快捷键时显示录入控件；打开应用时由按钮打开应用选择器；打开链接时显示网址输入框；打开文件或文件夹时由按钮打开文件选择器。取消原生选择器保留原值。 |
| 应用范围 | 「所有应用」「选择应用」 | 点「所有应用」清除已选范围。点「选择应用」打开原生应用选择器；选定有效应用后显示其名称。范围选择与「打开应用」动作的目标互不影响。 |
| 底部 | 按键读数、「取消」「保存」 | 读数只显示当前编辑窗口中的按键或鼠标键，约 1.4 秒后清除。取消（`Esc`）丢弃草稿；录制快捷键时先取消录制。保存是默认操作，校验通过并写入后才关闭。 |

确认弹窗宽 360。信息弹窗只有一个主按钮，默认文案为「知道了」。需要确认时显示「取消」和明确的动作名称。普通确认为默认操作；删除用危险色按钮，确认快捷键为 `⌘Return`，不让裸 `Return` 默认删除。

## 5. 通用、关于与菜单栏

| 区域 | 控件 | 行为 |
| --- | --- | --- |
| 语言 | 短下拉框 | 简体中文／English；选择后即时刷新界面并记住选择。 |
| 外观 | 互斥按钮 | 跟随系统／浅色／深色；即时切换。 |
| 登录时启动 | 开关、「打开登录项」 | 注册或取消登录启动。系统要求批准时禁用开关，显示提示和跳转按钮；登录启动不主动弹出主窗口。 |
| 手势轨迹 | 开关、原生颜色选择器、粗细滑块 | 关闭时禁用样式行。开启时颜色不提供透明度选项；粗细为 1–5 pt，取整数，旁边显示数值。颜色和粗细变化即时反映到样例。 |
| 应用图标 | 互斥按钮 | 程序坞／菜单栏／都不显示；最后一项提示可从「应用程序」重开，不会停止规则。 |
| 权限 | 两行「授权」／「查看」按钮，各宽 104 | 分别对应辅助功能与输入监控。缺权时显示锁和主按钮「授权」；有权时显示勾和次按钮「查看」。两种状态都可跳到对应系统设置。 |
| 配置 | 「导入」「导出」「打开配置文件夹」 | 导入接受 JSON 或 `.BABPreset`，读取并校验后先确认是否替换；成功时显示导入数量及适用的警告。导出使用原生保存面板生成 JSON；只保留当前动作使用的目标，不带已改掉的网址、路径或输出键。原生 JSON 的保存、导出和导入共用 256 MB 上限（至多 500 条规则，每条至多 4,096 点）；`.BABPreset` 仍限 4 MB。「打开配置文件夹」跳转 Finder。可用时显示最近保存时间。 |
| 排障 | 「在 Finder 中显示」 | 在 Finder 中选中诊断日志，不显示内部事件码或日志格式。 |
| 关于 | 无按钮 | 显示应用图标、名称、版本和简短说明。 |
| 菜单栏 | 「打开应用」「退出应用」 | 使用原生菜单。前者显示主窗口，后者退出进程并停止规则。 |

## 6. 变更验收

- **按钮**：查默认、按下、选中、禁用和键盘焦点状态。图标按钮须有可读标签；验证取消不保存、删除不被裸 `Return` 触发。
- **下拉框**：查占位、禁用、展开、选定和关闭；切换动作分类不写入草稿。用中英文检查长标签，确认键盘焦点可辨认。
- **滚动**：用长规则列表、长动作分类和长提示验证最后一项仍可到达；列表表头和编辑器底部按钮不随内容移动。在滚动条隐藏时检查鼠标滚轮、触控板和键盘焦点移动。
- **规则**：核验应用专用规则覆盖、相同范围冲突、保存失败保留草稿、快捷键录入取消、`Ctrl+1` 注册失败仅提示且不改规则。
- **右键拖动**：该键有手势规则时，右键拖动未匹配手势不弹出系统菜单，拖回起点也不弹；普通右键单击仍弹出菜单；没有手势规则时右键拖动照常传递。
- 规则和前台应用保持不变时，权限轮询复用已有的冲突检查结果和按键绑定。注册失败的快捷键仍应在后续轮询时重试。
- 用两条相近的手势测试歧义。失败日志应记录候选规则 ID、对应距离及判定阈值。只有一个候选时记录一项，无可用评分时记录原因。
